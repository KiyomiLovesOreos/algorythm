HOW TO USE:
================================================================================

Primary Method (Recommended):
  $ algorythm studio

  - Launches Terminal DAW in Live Coding view
  - Works without GUI dependencies
  - Full feature set available

Alternative Method:
  $ algorythm-live

  - Launches tkinter GUI (if available)
  - Shows helpful error if tkinter missing
  - Directs to 'algorythm studio' as alternative

Key Controls in Live Coding View:
  Ctrl+R  - Run code
  Ctrl+P  - Play generated audio
  Ctrl+S  - Save audio/project
  1-6     - Switch views
  Q       - Quit
