# Algorythm Documentation

Complete wiki for making music with Python.

## What is This?

This is the complete documentation for Algorythm, a Python library for creating music with code. It covers everything from basic sound generation to advanced composition techniques.

## Document Descriptions

### GETTING_STARTED.md
Installation, first sound, basic concepts. Best for complete beginners.

### QUICK_REFERENCE.md
One-page overview with common patterns and parameters. Keep this open while coding.

### MUSIC_MAKING_REFERENCE.md
Practical reference while composing: tempo calculations, scale reference, drum patterns, mixing levels. Essential companion while working.

### SYNTHESIS.md
All synthesis engines (Basic, FM, Wavetable, Physical, Additive, Granular), 45+ presets, sound design techniques.

### SEQUENCING.md
Scales, motifs (melodies), rhythms, chords, arpeggios, microtonal tunings.

### EFFECTS.md
Complete effects reference: reverb, delay, distortion, compression, modulation, creative effects. Includes parameters and practical settings.

### COMPOSITION.md
Multi-track arrangement, timing, mixing, panning, automation, rendering.

### GENERATIVE.md
Algorithmic composition: L-Systems, Cellular Automata, Genetic Algorithms, Markov chains, data sonification.

### VISUALIZATION.md
Creating video from audio: visualizer types, video settings, custom visualizers, optimization.

### THEORY.md
Music theory essentials: intervals, chords, scales, harmony, melody composition, tension/resolution.

### COOKBOOK.md
50+ copy-paste code recipes: basic sounds, melodies, drums, effects, full compositions, visualization, randomization.

### GENRES.md
Genre-specific guides: EDM, Hip-Hop, Rock, Jazz, Ambient, Lofi, House, Classical, Synthwave. Each with structure and recipes.

### TROUBLESHOOTING.md
Common problems and solutions: no sound, distortion, timing issues, effects problems, export failures, performance issues.

### API_REFERENCE.md
Complete API documentation for all modules and classes.

### GLOSSARY.md
150+ music and audio terms defined simply.

### INDEX.md
Complete table of contents and navigation guide.

## How to Use This Wiki

### While Learning
1. Read guides in order (GETTING_STARTED → SYNTHESIS → SEQUENCING, etc.)
2. Try examples from COOKBOOK
3. Reference terms in GLOSSARY as needed

### While Composing
1. Keep MUSIC_MAKING_REFERENCE.md open in second window
2. Reference GENRES.md for your style
3. Copy from COOKBOOK.md as needed

### When Stuck
1. Check TROUBLESHOOTING.md first
2. Look up terms in GLOSSARY.md
3. Read relevant section in appropriate guide

### When Searching
1. Use INDEX.md to find topic
2. Or search by "I want to..." patterns
3. Or navigate by concept (Synthesis, Effects, etc.)

## Tips

- **Start small**: Make beeps before songs
- **Test often**: Render and listen frequently
- **Use examples**: Copy from COOKBOOK, modify
- **Read theory**: Understand WHY things work
- **Reference music**: Analyze songs you like
- **Keep QUICK_REFERENCE open** while coding
- **Keep MUSIC_MAKING_REFERENCE open** while composing
